# What to Watch 🎬

Учебное веб-приложение на Flask для публикации мнений о фильмах.

Приложение показывает случайное мнение, позволяет добавлять собственные отзывы и прикреплять изображения. Данные хранятся в SQLite, а фотографии загружаются в Dropbox.

## Возможности

- Просмотр случайного мнения о фильме.
- Добавление мнения с названием фильма, текстом и ссылкой на обзор.
- Проверка обязательных полей и повторяющихся текстов.
- Прикрепление нескольких изображений.
- Параллельная загрузка фотографий в Dropbox.
- Отдельная страница каждого мнения.
- JSON API для просмотра, создания, изменения и удаления мнений.
- Загрузка начальных данных из CSV.
- Страницы ошибок 404 и 500.

## Технологии

## Установка и запуск

Команды ниже предназначены для macOS и Linux и выполняются из корневой папки проекта.

### 1. Клонирование репозитория

```bash
git clone https://github.com/ludochka18/what-to-watch.git
cd what-to-watch
```

### 2. Создание виртуального окружения

```bash
python3 -m venv venv
```

### 3. Установка зависимостей

```bash
./venv/bin/python3 -m pip install -r requirements.txt
```

Если в `requirements.txt` указаны только Flask и python-dotenv, дополнительно установите библиотеки, необходимые текущей версии приложения:

```bash
./venv/bin/python3 -m pip install "Flask[async]==3.0.2" Flask-SQLAlchemy Flask-Migrate Flask-WTF requests aiohttp certifi
```

### 4. Настройка переменных окружения

Создайте файл `.env` в корне проекта:

```dotenv
FLASK_APP=opinions_app:app
DATABASE_URI=sqlite:///db.sqlite3
SECRET_KEY=replace-with-a-random-secret
DROPBOX_TOKEN=replace-with-your-dropbox-token
```

| Переменная | Назначение |
| --- | --- |
| `FLASK_APP` | Модуль приложения и объект Flask |
| `DATABASE_URI` | Адрес подключения к базе данных |
| `SECRET_KEY` | Секретный ключ приложения |
| `DROPBOX_TOKEN` | Токен для обращения к Dropbox API |

Сгенерируйте значение `SECRET_KEY`:

```bash
./venv/bin/python3 -c 'import secrets; print(secrets.token_hex(32))'
```

Скопируйте результат в `.env` вместо `replace-with-a-random-secret`.

Для загрузки фотографий укажите действующий токен приложения Dropbox с разрешениями на запись файлов и создание общих ссылок.

**Не публикуйте файл `.env` и токены в репозитории.**

### 5. Подготовка базы данных

В текущем проекте первая миграция добавляет поле `added_by` к существующей таблице, а следующая — поле `images`. Миграции создания самой таблицы пока нет.

#### Первый запуск с новой пустой базой

Откройте Flask shell:

```bash
./venv/bin/python3 -m flask --app opinions_app:app shell
```

Выполните в открывшейся Python-консоли:

```python
from opinions_app import db

db.create_all()
exit()
```

Затем в терминале отметьте созданную схему как соответствующую текущим миграциям:

```bash
./venv/bin/python3 -m flask --app opinions_app:app db stamp head
```

> Этот порядок подходит только для новой базы, созданной по текущим моделям. Команда `stamp` сама не создаёт и не изменяет таблицы.

#### Обновление существующей базы

Если база уже существует и используется с миграциями:

```bash
./venv/bin/python3 -m flask --app opinions_app:app db upgrade
```

### 6. Загрузка начальных данных

Для наполнения пустой базы выполните:

```bash
./venv/bin/python3 -m flask --app opinions_app:app load_opinions
```

При успешной загрузке поставляемого набора:

```text
Загружено мнений: 20
```

Повторный импорт одинаковых мнений вызовет ошибку уникальности текста. При сбое импорта часть записей может уже сохраниться, поскольку команда добавляет их по одной.

### 7. Запуск сервера

```bash
./venv/bin/python3 -m flask --app opinions_app:app run --debug
```

Приложение будет доступно по адресу:

**http://127.0.0.1:5000**

Для остановки сервера нажмите `Ctrl+C`.

Режим `--debug` предназначен для локальной разработки.

## Использование приложения

1. Откройте главную страницу, чтобы увидеть случайное мнение.
2. Нажмите «Добавить мнение о фильме».
3. Укажите название и текст мнения.
4. При желании добавьте ссылку на обзор и изображения.
5. Отправьте форму — приложение откроет страницу созданного мнения.

Поддерживаемые расширения изображений:

- `.jpg`
- `.jpeg`
- `.png`
- `.gif`
- `.bmp`

Для каждого файла приложение сначала загружает изображение в Dropbox, затем получает ссылку. Разные изображения обрабатываются параллельно.

## Страницы приложения

| Адрес | Назначение |
| --- | --- |
| `/` | Случайное мнение |
| `/add` | Форма добавления мнения |
| `/opinions/<id>` | Страница конкретного мнения |

## JSON API

| Метод | Адрес | Действие | Код успешного ответа |
| --- | --- | --- | --- |
| `GET` | `/api/opinions/` | Получить список мнений | `200` |
| `GET` | `/api/opinions/<id>/` | Получить мнение по ID | `200` |
| `POST` | `/api/opinions/` | Создать мнение | `201` |
| `PATCH` | `/api/opinions/<id>/` | Изменить мнение | `201` |
| `DELETE` | `/api/opinions/<id>/` | Удалить мнение | `204` |
| `GET` | `/api/get-random-opinion/` | Получить случайное мнение | `200` |

Коды ответов соответствуют текущей реализации, включая `201` для `PATCH`.

### Получение списка мнений

```bash
curl http://127.0.0.1:5000/api/opinions/
```

### Получение мнения по ID

```bash
curl http://127.0.0.1:5000/api/opinions/1/
```

### Создание мнения

```bash
curl -X POST http://127.0.0.1:5000/api/opinions/ \
  -H "Content-Type: application/json" \
  -d '{
    "title": "Интерстеллар",
    "text": "История о времени, семье и исследовании космоса.",
    "added_by": "movie_fan"
  }'
```

Для создания мнения обязательны поля `title` и `text`. Поля `source` и `added_by` необязательны.

Одиночное мнение возвращается под ключом `opinion`, список — под ключом `opinions`.

Изображения загружаются через веб-форму. Текущая версия API не принимает поле `images` и не включает его в JSON-ответы.

## Работа с миграциями

После изменения модели создайте миграцию:

```bash
./venv/bin/python3 -m flask --app opinions_app:app db migrate -m "describe changes"
```

Проверьте сгенерированный файл и примените изменения:

```bash
./venv/bin/python3 -m flask --app opinions_app:app db upgrade
```

## Особенности текущей версии

- При пустой базе главная страница возвращает ошибку `500`, а API случайного мнения — `404`.
- API не содержит авторизации и проверки владельца записи.
- Ошибки Dropbox могут приводить к ответу `500`.
- Удаление мнения из базы не удаляет соответствующие файлы из Dropbox.
- Для HTTPS-запросов через aiohttp используется проверка сертификатов с помощью certifi.
- Приложение предназначено для учебного локального запуска.
